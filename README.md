## 🌟 Sobre o Repositório

Este repositório armazena as minhas **Ferramentas de Programação**, configurações pessoais (*dotfiles*) e scripts de automação de ambiente que utilizo no meu dia a dia como Desenvolvedor e Professor de Ciência da Computação. 

O foco principal destas ferramentas é aumentar a produtividade no terminal, oferecendo atalhos otimizados, configurações robustas para editores de texto (como o Vim) e scripts utilitários em Shell.

### ✨ O que você vai encontrar aqui:

- **Configurações do Vim (`.vimrc`)**: Meus plugins preferidos, atalhos de teclado, macros e temas de sintaxe otimizados para programar em C, Java, Python e algoritmos.
- **Automação em Shell Script**: Scripts criados para facilitar tarefas do cotidiano, rotinas de backup, e preparação de ambientes de desenvolvimento.
- **Aliases e Configurações de Terminal**: Ajustes para deixar o uso terminal muito mais rápido e inteligente.

## 🚀 Como Utilizar

Se você quiser testar ou aplicar essas configurações no seu próprio ambiente, siga os passos abaixo:

### 📋 Pré-requisitos
- Sistema Operacional Linux ou macOS (também utilizável via WSL no Windows).
- `git` e `vim` instalados na máquina.

### 🔧 Instalação

1. Clone este repositório para o seu diretório pessoal (Home):
```bash
git clone https://github.com/ed1rac/FerramentasProgramacao.git ~/FerramentasProgramacao
```

2. Acesse a pasta do projeto:
```bash
cd ~/FerramentasProgramacao
```

3. Explore os diretórios e faça links simbólicos (`ln -s`) para os arquivos que deseja usar em seu sistema, como por exemplo:
```bash
ln -s ~/FerramentasProgramacao/.vimrc ~/.vimrc
```
*(Nota: Sempre faça um backup das suas configurações atuais antes de sobrescrevê-las!)*
