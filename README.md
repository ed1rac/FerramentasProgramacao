## 📌 Principais Scripts do Repositório

| Script / Arquivo | O que ele faz? |
| :--- | :--- |
| `LinuxMint-posInstall.sh` | Automação pós-formatação para Linux Mint / Ubuntu: instala navegadores, editores, reprodutores e utilitários essenciais com 1 comando |
| `configura_bash_oh_my_posh_com_fontes.sh` | Baixa Nerd Fonts e instala o motor de prompt moderno **Oh My Posh** no Bash |
| `instala-config-geral-debian.sh` | Configuração geral de pacotes e repositórios base para sistemas Debian |
| `instala-alpine.sh` | Configuração rápida de ambientes mínimos baseados em Alpine Linux |
| `config_proxy.sh` & `config_proxy.md` | Configuração e chaveamento rápido de proxy corporativo/universitário no terminal e no Git |
| `vim-temas/` & `nano/` | Configurações do `.vimrc` com esquemas de cores de alto contraste e realce de sintaxe |

---

## 🚀 Como Executar o Script Pós-Instalação

```bash
chmod +x LinuxMint-posInstall.sh
./LinuxMint-posInstall.sh
```
